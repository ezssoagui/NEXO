# Visão do produto
> Desdobramento técnico do Documento Mestre v1.0 (fonte de verdade). Em caso de conflito, prevalece o mestre. Referências no formato etapa.subtópico.

- **O quê (1.1):** plataforma web de preparação adaptativa exclusiva para o ENEM (1.2), para estudo independente ou complementar.
- **Diferencial (1.4):** rota individual — mesmo currículo, ordem/intensidade/atividades conforme evidências (`src/modules/adaptive-engine`).
- **Princípios (1.5–1.9):** aprendizagem ativa; acertos ≠ cobertura ≠ domínio ≠ retenção; autonomia sem cronograma, bloqueios ou penalidade por inatividade; IA apenas onde agrega valor; nenhuma promessa de nota/aprovação.
- **Fora do MVP (A.1/14.1):** apps nativos, gestão escolar, afiliados, licenciamento integrado, videoaulas, outros exames.
- **Estado:** software implementado e testado localmente; acervo oficial, conteúdo validado, credenciais, revisão jurídica e piloto pendentes (ver `docs/ESTADO_DO_PROJETO.md`).
