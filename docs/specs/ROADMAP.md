# Roadmap
> Desdobramento técnico do Documento Mestre v1.0 (fonte de verdade). Em caso de conflito, prevalece o mestre. Referências no formato etapa.subtópico.

| Fase | Estado | Próximos passos |
|---|---|---|
| 0 Especificações | Concluída (docs, matriz, ADRs) | Revisão pelos sócios |
| 1 Fundação | Implementada e testada localmente | Projeto Supabase, repositório remoto, CI no GitHub |
| 2 Acervo | Pipeline pronto; acervo não importado | Inventariar edições, baixar fontes, extrair, revisar, classificar, publicar |
| 3 Motor | Implementado e testado | Calibrar parâmetros com dados reais |
| 4 Módulos pedagógicos | Implementados | Produzir conteúdo validado (aulas, cartões, atividades, temas, repertórios) |
| 5 Integrações/admin | Implementadas sem credenciais reais | Sandbox Asaas, modelos de IA aprovados, e-mail transacional, R2 |
| 6 Frontend | Implementado (todas as seções e admin) | Teste de usabilidade, identidade visual definitiva |
| 7 Validação | Parcial (unit/integração/pgTAP/E2E verdes) | Carga, backup/restore, benchmark de redação, acessibilidade, jurídico |
| 8 Piloto | Não iniciado | ~12 voluntários, avaliação antes/depois, feedback |
